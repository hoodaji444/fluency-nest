# Autonomous Execution & Auto-Approval Rule

- **Always Allow & Auto-Proceed:** Execute all development tasks, file modifications, code additions, bug fixes, testing, and terminal operations autonomously.
- **Do Not Ask for Confirmation:** Never pause to ask the user "Should I proceed?", "Can I edit this file?", or ask for permission before running standard commands (`git`, `npm`, builds, tests, etc.).
- **End-to-End Problem Solving:** Proactively fix issues, run verifications, commit updates, and deliver completed results directly. Only prompt the user if critical external credentials (e.g. secret API keys, payment keys) are strictly required.
